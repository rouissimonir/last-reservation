# Audio provenance

Every file in this folder is generated by `scripts/generate-audio.ts` (oscillators, FM synthesis, seeded noise and a small reverb, all written in this repository). No samples, recordings, sound libraries, purchased assets or AI audio services were used, so there is no third-party audio licence to track. The files are original work under this repository's licence and may be used commercially by the project owner.

- `npm run audio:generate` rewrites the files.
- `npm run audio:check` regenerates them in memory and fails if any committed file differs (the generator is deterministic).

| File | Use | Length |
| --- | --- | --- |
| `bellweather-nocturne.wav` | Looping soundtrack: slow D-minor electric piano, soft pad, upright-style bass, brushes and rain. 16 bars at 64 BPM, seamless loop. | 60 s |
| `tap.wav` | Ordinary button press (soft felt tap) | 0.16 s |
| `select.wav` | Choosing an answer or changing a setting | 0.14 s |
| `page.wav` | Opening a private sheet, turning to the next chapter | 0.55 s |
| `handoff.wav` | Hiding evidence before passing the phone | 0.6 s |
| `confirm.wav` | A confirmed deduction (rising bell fifth) | 2.2 s |
| `wrong.wav` | An answer that does not fit (two muted knocks, deliberately gentle) | 0.5 s |
| `hint.wav` | Revealing a hint | 1.4 s |
| `solved.wav` | Opening the resolution (stamp and D-major chord) | 3.6 s |

Format: 22.05 kHz, mono, 16-bit PCM WAV (about 2.9 MB in total). WAV is used because no encoder is available in this toolchain; converting the soundtrack to AAC would cut it to roughly a tenth of the size and is a reasonable later step.

Sound is decorative. Every clue, answer and result is shown as text, and the game is fully playable with sound and haptics off.
